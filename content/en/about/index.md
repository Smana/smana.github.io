{{< pf-hero image="profile_2024.jpg" name="Smaïne Kahlouch" tagline="Tech Lead · Freelance Platform Engineer · Open Source & Cloud Native" >}}
I'm a **freelance Tech Lead and Platform Engineer** with twenty years of experience building cloud-native platforms that stay calm in production and out of developers' way — spanning SRE, cloud migrations, and leading engineering teams (currently supporting **Electra**).

Lately, much of my open-source work sits at the intersection of **Kubernetes and agentic AI**: building tools like [Maku](https://maku.ogenki.io) and [RunLore](https://github.com/Smana/runlore) to turn autonomous coding and incident investigation into audited, repeatable engineering workflows.

This blog is my lab notebook — real architectures, production trade-offs, and working code across Kubernetes, GitOps, security, [observability](/series/observability/), and [agentic AI](/series/agentic-ai/).
{{< /pf-hero >}}

## Open source

Most of what I write about is backed by working code on [GitHub](https://github.com/Smana). Three projects I actively build and maintain:

{{< pf-cards variant="oss" >}}
{{< pf-card title="Maku" subtitle="Open-source software factory for Kubernetes" link="https://maku.ogenki.io" featured="true" meta="Kubernetes · Sandboxed agents · Helm · Go" >}}
Run autonomous coding agents on your own cluster with isolated sandboxes, audited collaboration rooms, strict budgets, upkeep routines, and policy-backed merge gates — no SaaS lock-in.
{{< /pf-card >}}
{{< pf-card title="cloud-native-ref" subtitle="Reference Kubernetes platform" link="https://github.com/Smana/cloud-native-ref" meta="EKS · Flux GitOps · Crossplane · Cilium" >}}
An opinionated cloud-native reference platform covering GitOps, Crossplane, security, and observability. The backbone of many hands-on posts on this blog.
{{< /pf-card >}}
{{< pf-card title="RunLore" subtitle="AI-powered SRE agent" link="https://github.com/Smana/runlore" meta="Go · Kubernetes · Root-cause analysis · OpenKB" >}}
An open-source SRE companion that investigates incidents, narrows down the likely root cause fast, and turns every resolution into reviewable knowledge.
{{< /pf-card >}}
